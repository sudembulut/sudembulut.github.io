Research · TÜBİTAK 2209-A · 2026

Real-time regional density detection in outdoor spaces using a low-cost IoT network

The project started from one question: can you estimate crowd density and movement outdoors without expensive cameras or GSM data? The approach uses low-cost ESP32 nodes that passively observe Wi-Fi signal patterns in the environment.

The hard part is the signal itself. Outdoor RSSI is badly behaved — it reflects off buildings, gets blocked by people and vehicles, and shifts constantly with the surroundings. Rather than chasing exact positions, the problem is framed as regional classification: readings from several reference sensors should form a distinct signal fingerprint for each zone. A machine learning model learns those fingerprints, and Kalman filtering suppresses noise enough to expose movement trends over time.

The goal is a system that estimates density and flow direction cheaply, at an anonymous and aggregate level — no one is identified or tracked. It was selected for funding under TÜBİTAK's 2209-A programme, and first field data was collected in Taksim Square.

Competition · First place · 2026

Proactive GenAI for mobile experience failures

Built for the Akbank Case Marathon, hosted with the ITU Mathematics and Computer Club. The brief was the ordinary misery of mobile banking: battery drain, biometric authentication failures, crashes.

Most fixes for these are reactive — something breaks, the user complains, someone investigates. We built an autonomous GenAI system that resolves the issues as they surface instead, so the fault is handled before it reaches the customer. The entry took first place.
